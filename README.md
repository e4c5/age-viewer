# What is Apache AGE Viewer

Apache AGE Viewer is a clean room implementation of a web-based user interface for visualizing graph data stored in a PostgreSQL database with the AGE extension. This is a graph visualization tool for Apache AGE.

This is a sub-project of [the Apache AGE project](https://age.apache.org/#).

## Development Status

This project is currently under active development as a clean room implementation. Documentation and features will be added as development progresses.
